# Dustdaman Sikh Society

Welcome to the official repository for the **Dustdaman Sikh Society** website. 
This project is a fully responsive, bilingual (English & Punjabi) static website designed to serve the Sangat of Surrey, BC.

## 🌟 Features
- **Bilingual Interface:** Seamlessly toggle between English and Punjabi.
- **Admin Dashboard:** Secure Firebase-powered authentication allowing authorized admins to upload Gallery photos and YouTube videos without touching code.
- **Dynamic Gallery:** Automatically categorizes uploaded photos and videos into Smart Folders (Kirtan & Paath, Langar Seva, Special Events, etc.).
- **Live Google Reviews:** Integrated Elfsight widget to display real-time Google Reviews.
- **Modern UI:** Built with smooth animations, seamless marquee banners, and alternating backgrounds.

- **Backend/Storage:** Google Firebase (Firestore)
- **Forms:** Formspree
- **Fonts & Icons:** Google Fonts (Lora, Noto Sans Gurmukhi), FontAwesome
